보유 시약 전수 조사 데이터 (2026)

🚨 사고 발생 시 즉시 119 연결
강산 / 부식성

염산 (HCl 35%, 9%, 5%)

위험: 강한 부식성, 증기 흡입 시 호흡기 손상.

대응: 다량의 물로 세척, 보안경 필수.

강산 / 탈수

황산 (H2SO4)

위험: 물과 반응 시 격렬한 열 발생. 유기물 파괴.

대응: 접촉 시 마른 헝겊으로 닦은 후 다량 세척.

강염기 / 단백질녹임

수산화나트륨 (NaOH)

위험: 피부 및 안구 손상 위험 매우 높음.

대응: 미끈거림이 없을 때까지 물로 세척.

금속화재 / 폭발

나트륨 금속 (Na)

위험: 물과 반응 시 폭발 및 수소가스 발생.

대응: 물 접촉 절대 금지. 마른 모래 사용.

인화성 / 유기용제

헥산 / 아세톤 / 부탄올

위험: 인화성이 매우 강함. 화재 주의.

대응: 화기 엄금, 환기 시설 가동.

산화성 / 변색

질산은 / 질산납

위험: 중금속 독성, 피부 변색 유발.

대응: 폐액 처리 규정 준수, 장갑 착용.

산화제

과망간산칼륨 / 과산화수소

위험: 강한 산화성. 가연물과 혼합 시 발화.

대응: 서늘한 곳 보관, 직사광선 회피.

지시약

BTB / 페놀프탈레인 / 메틸오렌지

특징: pH에 따른 색깔 변화 확인용.

대응: 섭취 금지, 눈에 들어가지 않게 주의.

염류 / 파우더

염화나트륨 / 탄산칼슘 / 염화칼슘

특징: 일반 실험용 염류.

대응: 가루 날림 주의, 실험 후 손 씻기.

유기화합물

디클로로메탄 / 헥사메틸렌디아민

위험: 유해성 증기, 피부 자극.

대응: 후드 내 사용 권장.

생물 실험 시약

아밀라아제 / 말토즈 / 그람아이오딘

특징: 효소 및 세포 염색용 시약.

대응: 냉장 보관 확인, 오염 방지.
